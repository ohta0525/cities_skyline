# 瑞穂の街

**災害の多い日本の国土で、隣町と支え合い競いながら、100 年続く街をつくる。**

Cities: Skylines 2 を目標にした、ブラウザで遊べる 3D の街づくりゲームです。
企画とロードマップは [docs/DESIGN.md](docs/DESIGN.md) にまとめています。

## パソコンで遊ぶ（ダウンロード）

インストールは要りません。HTML ファイル 1 つで動きます。

1. [download/mizuho-city.html](download/mizuho-city.html) を開き、右上の「Download raw file」（下向き矢印のボタン）を押して保存します
2. 保存した `mizuho-city.html` をダブルクリックすると、ブラウザ（Chrome／Edge／Firefox）で始まります

- ファイルは好きな場所に置けますが、置き場所を変えないほうが安全です（セーブデータはブラウザの中に、開いた場所ごとに保存されるため）
- 大事な街は、セーブデータの画面の「書き出す」でファイルにしておくと、別のパソコンやブラウザでも「設定 → ファイルから読み込む」で続きを遊べます
- インターネットにつながっていなくても遊べます（文字の書体だけ、パソコンにあるものに変わります）
- 新しい版にするときは、同じ手順でファイルを取り直して上書きしてください

## タイトル画面・チュートリアル・セーブデータ

- **タイトル画面**：開くと最初に出ます。つづきから／はじめから／チュートリアル／セーブデータ／設定／操作方法。ゲーム中は右上の「タイトル」で戻れます（自動保存します）
- **チュートリアル**：10 ステップで基本を覚えます（カメラ → 道路 → 住宅地 → 時間 → 電気 → 水道 → 仕事 → 市役所 → ハザードマップ）。やることのボタンが光り、できると自動で次に進みます。チュートリアルの間は災害と紛争が起きません
- **セーブデータ**：右上の「保存」（Ctrl+S）と「読み込む」で開きます。8 つのスロットに、画面の縮小画像・日付・人口・資金・遊び方つきで保存できます。上書きと削除は 2 回押し。スロットごとにファイルへ書き出せます
- **自動保存**：毎月 1 日と、ページを閉じるとき・タイトルに戻るときに作られます（「つづきから」で再開）

## 街のつくり方

1. **道路**：下の「道路」を選び、クリックで始点、もう一度クリックで終点を置きます。終点から続けて引けます
   - 種類：路地（5 m）／生活道路（10 m）／幹線道路（18 m、中央分離帯つき）
   - 引き方：直線／曲線（始点 → 曲がる位置 → 終点）
   - 既存の道路や交差点に吸着し、交差すると交差点が自動でできます。川をまたぐと橋になります
   - 長さは 8 m 単位、向きは既存の道路と直角・平行にそろいます（Shift で吸着なし）
2. **区画**：用途地域を選んで、道路沿いのマスをドラッグで塗ります
3. **建物**：画面上の需要（住・商・工）に応じて、区画に建物が建っていきます
4. **地区**：町を塗り分けると、町名が自動で付きます（名前は変更可）
5. **施設**：発電所・浄水場・消防署・交番・病院・学校・公園・神社、防災や防衛の施設などを道路沿いに建てます
6. **交通**：一方通行、交差点（右折レーン・立体交差）、踏切の高架化
7. **公共交通**：バス・路面電車・鉄道・地下鉄。停留所や駅を順にクリックして Enter で路線ができます
8. **防災**：川岸の堤防（最大 3 段）と海岸の防潮堤（5 m／10 m）を高くします
9. **撤去**：建物・施設・道路・停留所・駅をクリックして取り壊します

市の土地は地図の真ん中です。東・西・北（山側）の白い点線の外は隣町の土地で、道路や建物は置けません。合併すると使えるようになります。

### 交通

- 朝の通勤の車は、住む場所から働く場所へ所要時間の短い道を選んで走ります（左側通行）。混んだ道路は遅くなり、別の道が選ばれます
- 渋滞がひどいと満足度と住宅の需要、経済界の支持が下がります。「情報」の交通量で混み具合を色分けして見られます
- 公共交通は、駅や停留所の近くに住む人が、同じ路線の別の駅の近くで働いていれば使います。本数・運賃・渋滞で利用者が変わります
- 地上の線路が道路と交わると踏切ができ、列車が多いと「開かずの踏切」になります。高架にすると解消します
- 駅の近くでは、マンションやビルが高くなります（駅前の発展）

### インフラとサービス

- 電線と水道管は道路に沿って通ります。発電所や浄水場と道路でつながった建物にだけ届きます
- 地図の端で隣町とつながっていれば、足りない電気・水などを買えます
- 電気や水道がないと建物が建ちにくく、満足度が下がります（建物の上に「電」「水」のしるし）
- 消防・警察・医療・教育は、施設から一定の範囲に届きます

### 災害

- 火災：木造の建物から出火し、消防署が遠いと燃え広がります。焼けた建物はがれきになります
- 地震：震度は震源からの距離と地盤で決まり、旧耐震・木造の建物ほど壊れやすく、液状化もあります。損傷した建物の屋根にはブルーシート
- 「情報」パネルでハザードマップ（浸水・液状化・土砂災害・揺れやすさ）を見られます
- 台風（8〜10 月）と梅雨の大雨（6〜7 月）：予報が出ると画面上に警報の帯が出て、警戒レベルが上がっていきます。「避難指示を出す」を早めに押せば逃げ遅れはいません（店や工場が止まるので費用がかかります）
- 洪水（堤防を越えると周りが浸水）、内水氾濫（下水が足りない低い土地）、高潮、土砂災害、強風
- 津波：海で起きた大地震のあと。防潮堤の高さを超えた分が押し寄せます。津波避難タワーや高台が近いと逃げられます
- 原発事故：強い揺れや防潮堤を越える津波で起きることがあり、半径 1.5 km が 12 年間の帰還困難区域になります
- 復興：国の激甚災害指定による支援、隣町からの応援、仮設住宅（足りないと人が市外へ出ていく）、防衛隊の災害派遣、復興区画整理、高台移転
- 設定から、災害のあり／なしの切り替えと、試しの地震・台風・大雨・津波ができます

### 隣町と外交

- 市の境界（白い点線）まで道路を引くと、その方角の隣町とつながり、通勤と交易が始まります
- 隣町ごとに関係（−100〜100）と緊張（0〜100）があります。緊張が高まると、外交摩擦 → 経済制裁（交易が止まる）→ 境界の封鎖（通勤も止まる）→ 小競り合い（境界近くに被害）→ 紛争 と進みます
- 協定：交易協定、災害時応援協定、広域連携（共同ゴミ処理）、不可侵条約、軍事同盟
- 手段：親善訪問、経済支援、抗議、交渉、譲歩、県に仲裁を頼む、経済制裁、宣戦布告
- 隣町からの要求（取水、境界線、ゴミ処分場、被災者の受け入れ）に、受けるか断るかを答えます。仲の悪い町は市長選挙に介入してきます
- ふるさと納税：返礼品の割合を決めます。多いほど寄付が集まりますが、3 割を超え続けると中央政府に制度から外されます。隣町と返礼品競争になることも
- 合併：関係が良く、緊張のない町に申し入れられます。議会が賛成すると、その町の土地と家並み・住民、借金を引き継ぎ、国から支援が入ります

### 防衛隊と紛争

- 「施設」の防衛：防衛隊駐屯地（部隊 6 つまで）、訓練場（力 1.25 倍）、沿岸監視所（艦艇）、航空基地（航空隊、41 年目から）、兵器工場（輸出と編成費の割引）、中央政府の基地の誘致（交付金と騒音）
- 部隊：歩兵隊、機動隊、救助隊（災害派遣で逃げ遅れを減らす）、艦艇、航空隊。駐屯地には部隊の車両が並びます
- 紛争は自動で進みます。部隊の力 × 訓練 × 士気（支持率）× 補給（資金）と相手の軍備で、5 日ごとに戦況が動きます。地図には前線と両軍の戦車、爆発が表示されます
- 攻められると最初は団結して支持率が上がりますが、長引くと厭戦気分で下がります。劣勢だと境界近くの建物が被害を受けます
- 講和：優勢なら賠償金を取り、互角なら白紙講和、劣勢なら賠償金を払います。勝てば、併合・賠償金・従属都市（10 年間の上納金）から結末を選べます。負けると賠償金と 5 年間の上納金
- 設定で「平和モード」にすると紛争は起きません

### 街の不満とクーデター

- 不満は、満足度・失業・支持率・住まいを失った人・治安で決まり、不満 → デモ → 暴動（建物が燃やされる）→ 過激派の武装化（施設が襲われる）と進みます。人口 1,000 人未満の町では暴動にはなりません
- 手段：対話集会、生活支援金、機動隊で鎮圧、戒厳令
- 部隊が 4 つ以上あるのに防衛派の支持が低いと、クーデターの危険が高まります。100 になると防衛隊が市役所を占拠し、市政が終わります（1 か月前から再開できます）。待遇改善や幹部の人事異動で下げられます

### 季節・昼夜・音・メディア

- 季節：春は桜、夏は濃い緑、秋は紅葉、冬は雪（地面・屋根・木に積もる）。年中行事（初詣・花見・梅雨入り・夏祭り・秋祭り）、大雪（除雪費）、猛暑
- 夏祭り：7 月に開くかどうかを決め、8 月の夜は川の上に花火が上がります
- 昼夜：見た目の 1 日は約 4 分。夜は窓に明かりがともり、街灯がつきます（設定で昼に固定できます）
- 音：風・雨・セミ・鳥・虫の声・風鈴、夕方 5 時の防災無線のチャイム、和風の lo-fi の音楽、警報音。音はすべてブラウザの中で合成しています
- 地元紙「〇〇新報」：毎月の一面と社説。ローカル FM（DJ が街の出来事を皮肉まじりに紹介）、市民の声（SNS 風）

- 関係者：私鉄社長（私鉄に路線を任せる、沿線開発）、建設会社社長、県知事、商工会議所会頭、記者。会食・視察・便宜、陳情、疑惑度、スクープ、リコール

- 道路網に沿った電気・水道・下水・ゴミの需給と、隣町からの購入
- サービスの届く範囲、建物ごとの満足度、犯罪と公害
- 火災（出火・延焼・消火・焼失）、地震（震度・倒壊・損傷・液状化・発電所の停止・火災）、がれきと修理
- ハザードマップ、情報表示、地区の政策と布告

### P2：経済と住民

- 財政：道路の建設費と維持費、税収、国からの交付金、市債、財政再生団体への転落と脱出
- 住民：年齢構成（時代で高齢化）、働き手、失業、人手不足、満足度、工業による公害
- 建物の建築年と耐震（31 年目に新耐震基準）、時代ごとの建物の階数と種類
- 人口の節目の補助金と、市 → 中核市 → 政令指定都市への昇格
- 政治：6 つの派閥、支持率、4 年ごとの市長選挙、公約とその評価
- 落選すると AI 市長（土建屋・エコ・ポピュリスト・タカ派）が 4 年間街を運営。野党として活動して返り咲きを狙う
- 隣町 3 つ：地図の端まで道路を引くとつながり、通勤と交易が始まる
- 地元紙の見出しとニュースの一覧

### P1：道路と区画

- 曲線道路、交差点の自動生成、吸着、橋、横断歩道
- 道路の下の地形の造成（勾配や盛り土が大きすぎる場所には置けない）
- 道路沿いの区画のマス、用途地域 6 種、需要に応じた建物の成長
- 日本風の建物 13 種類の手続き生成（窓はシェーダーで描画）
- 地区の塗り分けと町名、建物の情報表示、撤去

### P0：3D 基盤

- 河川平野と海岸の地形を自動生成（北に山、中央に平野、川が南の湾に注ぐ）
- ジオラマ風の表示：地層の断面、木の台座と真鍮の銘板、ミニチュア効果（周辺のぼかし）
- 森、波の立つ海、川
- Cities: Skylines 風のカメラ操作
- 復興暦の時計（4 月始まり）。1 年の長さは 5 ／ 15 ／ 30 分から選べる
- 保存と読み込み（ブラウザ内、ファイルへの書き出し）、毎月の自動保存
- 画質（高 ／ 中 ／ 低）とミニチュア効果の強さの設定

## 開発

```sh
npm install
npm run dev        # 開発サーバー（http://localhost:5173）
npm test           # テスト
npm run typecheck  # 型チェック
npm run build      # 本番ビルド（dist/）
npm run build:single  # 1 つの HTML にまとめる（download/mizuho-city.html）
```

改造したい場合は、[Node.js](https://nodejs.org/)（LTS 版）を入れてから、このリポジトリを「Code → Download ZIP」か `git clone` で取り込み、上のコマンドを実行します。

### 構成

| 場所 | 役割 |
| --- | --- |
| `src/world/` | 地形の生成と参照（標高、川、森） |
| `src/city/` | 街の状態とルール（道路網、区画、建物、地区、財政、政治、施設、災害、交通、公共交通、関係者、外交、防衛）。描画から独立していてテストできる |
| `src/ui/` | 道具の操作、市役所のパネル、セーブデータの画面、チュートリアル |
| `src/sim/` | シミュレーション。Web Worker で描画と別スレッドで動く |
| `src/render/` | Three.js による 3D 表示（地形、水、木、ジオラマ、カメラ、ポストエフェクト） |
| `src/save/` | セーブデータ（自動保存は localStorage、スロットは IndexedDB） |
| `src/core/` | 乱数、ノイズ、設定 |
| `tests/` | テスト（Vitest） |

`main` 相当の既定ブランチに push すると、GitHub Actions でテストとビルドを行い、GitHub Pages に公開します。
