# ミニシティ

シティーズ：スカイラインのような街づくりゲームを、ブラウザで遊べる形で作っていくプロジェクトです。
HTML / JavaScript（Canvas）だけで動くので、インストールは不要です。

## 遊び方

- **ローカル**: `index.html` をダウンロードして、ブラウザで開くだけ。
- **GitHub Pages**: リポジトリの Settings → Pages で「Deploy from a branch」を選び、ブランチを指定すると `https://<ユーザー名>.github.io/cities_skyline/` で遊べます。

### 操作

| 操作 | 内容 |
| --- | --- |
| ドラッグ | 選んだツールで建設（道路は直線、ゾーンは四角形） |
| 右ドラッグ / Space+ドラッグ / 「移動」ツール | 地図の移動 |
| ホイール / ＋− ボタン / 2本指ピンチ | ズーム |
| 1〜7 キー | ツール切替 |
| P キー | 一時停止 / 再開 |

### ルール（v0.1）

- 道路の近く（2マス以内）にゾーンを置くと、需要に応じて建物が育ちます。道路から遠いゾーンには赤い「!」が出ます。
- **住宅(R)** は人口、**商業(C)・工業(I)** は雇用を生みます。画面上部の R/C/I バーが需要です。
- **公園** の近くの住宅・商業は育ちやすく、**工業** の近くの住宅は育ちにくくなります。
- 毎月、税収から道路・公園の維持費を引いた額が資金に加算されます。
- 進行状況はブラウザに自動保存されます（毎月）。

## 開発の進め方

やりたいことを日本語で伝えてもらえれば、Claude が実装してこのリポジトリにコミットします。
例えば次のような追加ができます：

- 電気・水道・ゴミ処理などのインフラ
- 警察・消防・学校・病院のサービス範囲
- 交通シミュレーション（車が道路を走る、渋滞）
- 地形（川・海・山）や建物の見た目の強化、3D表示
- 税率の調整、予算画面、ローン
- 実績・マイルストーン（人口に応じて新しい建物が解放される）
