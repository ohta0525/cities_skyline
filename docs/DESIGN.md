# 企画書 v1.0（確定）

> 2026-09-26 に確定した企画書です。開発はこの内容とロードマップに沿って進めます。
> 変更するときは、この文書を更新してから実装します。

## 1. コンセプト

**災害の多い日本の国土で、隣町と支え合い競いながら、100年続く街をつくる**

- Cities: Skylines 2 の主要機能を再現する
- 3D・ジオラマ風の高品質スタイライズドなグラフィック
- 独自の柱：**日本らしさ**、**災害と防災**、**隣の都市（外交と防衛）**、**コネと政治**

### ゲームの流れ

日本らしい街をつくる → その特徴が災害リスクを生む → 災害や紛争が街を試す → 隣の都市と支え合い、ときに競い、ときに争いながら立て直す → 100 年後に何が残るか

| 日本らしい要素 | 生まれるリスク |
| --- | --- |
| 木造住宅が密集した下町、狭い路地 | 火災が燃え広がる。消防車が入れない |
| 海の埋め立て地 | 液状化、津波 |
| 山を削った住宅地 | 土砂災害 |
| 川沿いの平野 | 洪水、堤防の決壊 |
| 川の上流と下流に分かれた隣町 | 水利権をめぐる対立 |

## 3. 世界観

戦争を入れるため、現実の日本そのままではなく**架空の日本風の列島国家**を舞台にする。

- **国名**：仮に「瑞穂（みずほ）連邦」とする（ほかの案：秋津洲、八雲国）
- **始まり**：「大震災」で中央政府の力が弱まり、「自治都市法」が施行された。各市は自前の予算・防衛隊・外交権を持つようになった。プレイヤーは新設された小さな市の初代市長
- **意味**：災害が物語の起点になり、隣町どうしの競争や紛争にも理由ができる。現実の国や歴史を直接扱わずに済む
- **暦**：架空の「復興暦」。1 年目から 100 年目まで
- **トーン**：ジオラマの見た目と、Tropico のような軽い風刺。流血の描写はしない

### 時代（約 20 年ごと）

| 時代 | 年 | 主な解放要素 | 主な課題 |
| --- | --- | --- | --- |
| 再建期 | 1〜20 | 木造住宅、バス、路面電車、小規模発電 | 資金不足、仮設住宅 |
| 成長期 | 21〜40 | 団地、鉄道網、工業地帯、高速道路 | 公害、渋滞、人口急増 |
| 繁栄期 | 41〜60 | 高層ビル、地下鉄、高速鉄道 | 地価高騰、バブルとその崩壊 |
| 成熟期 | 61〜80 | 再開発、再生可能エネルギー | 高齢化、空き家、インフラ老朽化 |
| 未来期 | 81〜100 | 自動運転、ドローン、災害に強いスマートシティ | 100 年目の評価 |

## 4. 用途地域（6 種類）

| 区画 | 建つもの | 混在 |
| --- | --- | --- |
| 低層住宅 | 戸建て、低層アパート | 小さな店舗兼住宅のみ |
| 中高層住宅 | マンション、団地、タワマン | 1 階に店舗 |
| 近隣商業 | 商店街、コンビニ、スーパー | 住宅も可 |
| 商業 | オフィス、百貨店、繁華街、ホテル | 住宅も可 |
| 準工業 | 町工場、倉庫、物流センター | 住宅も可（騒音あり） |
| 工業 | 工場、コンビナート、兵器工場 | 住宅不可 |

- 建物は**建築年代（旧耐震／新耐震）**を持ち、古い建物ほど地震に弱い
- 建つ建物のスタイルは時代によって変わる（木造 → 団地 → 高層）
- 高さ制限、防火地域などは地区ごとの政策で上乗せする

## 5. 住民

- 一人ひとりが年齢、世帯、学歴、職業、所属派閥、満足度、住んでいる建物を持つ
- **人生**：誕生 → 学校 → 就職 → 結婚 → 退職 → 死亡。成熟期には高齢化が進む
- **満足度の要素**：住まい、仕事、治安、医療、教育、交通、環境、防災、自由
- 不満が続くと引っ越し（隣町へ流出）、デモ、最終的には暴動につながる

## 6. 経済と財政

- **歳入**：住民税、法人税、固定資産税（地価に連動）、公共交通・水道の料金、国からの交付金（中央政府との関係に連動）、ふるさと納税、観光、電気・水・ゴミの売却、市債
- **歳出**：施設の維持費、サービス、防災、防衛隊、借金の利払い
- **予算**：毎年、市長が予算を組む（市議会はない）
- **破綻**：借金の指標が限界を超えると「財政再生団体」に転落し、政策が大きく制限される

## 7. インフラとサービス

- **電力**：火力、水力、風力、太陽光、地熱、原子力（後期。事故のリスクあり）。送電網で届ける
- **水**：浄水場、給水塔、配管、下水処理場
- **ゴミ**：焼却場、埋立地、リサイクル（建設地を決めると反対運動が起きる）
- **消防**：消防署、**消防団**（住民のボランティア、日本らしい要素）
- **警察**：警察署、**交番**
- **医療**：診療所、総合病院、救急
- **教育**：小学校、中学校、高校、大学
- **福祉**：保育園、介護施設
- **文化**：神社、寺、公民館、図書館、公園
- **行政**：市役所、支所

停電・断水は、電線や水道管のつながりに沿って広がる。

## 8. 交通

- **公共交通**：バス、路面電車、鉄道、地下鉄、フェリー。停留所・路線・本数・運賃の編集、系統番号、駅ナンバリング（「K05」など）
- **私鉄**：私鉄会社が沿線開発と、ターミナル駅の百貨店を手がける。関係が良ければ路線を提案でき、相互直通運転もできる
- **渋滞対策**：車線、一方通行、右折レーン、信号制御、立体交差、バイパス、踏切の高架化、パークアンドライド、時差出勤、ロードプライシング
- **可視化**：渋滞ヒートマップ、通勤の流れ

## 9. 地区と政策

- 地区を塗り分けて町名を付ける（「○○町一丁目」を自動生成）
- **地区の政策**：高さ制限、景観条例、防火地域、耐震補助、空き家対策、路上喫煙禁止
- **市全体の布告**（Tropico 風）：夜間外出禁止令、祭りの開催、減税キャンペーン、節電要請、非常事態宣言、戒厳令

## 10. 災害と防災

- **災害の種類**：地震（揺れ・液状化・火災）、津波、台風（暴風・高潮）、豪雨（洪水・内水氾濫・土砂災害）、大雪、猛暑、火山、原発事故
- **平時**：ハザードマップ表示、防災インフラ（堤防、遊水地、防潮堤、避難タワー、防災公園、延焼を止める広い道路、地下放水路）、耐震化の補助、防災訓練
- **予兆**：警報レベルの中で、いつ避難指示を出すかを決める。早すぎれば経済が止まり、遅すぎれば被害が出る
- **発災**：スロー再生、緊急車両と防衛隊の出動、停電・断水の連鎖、帰宅困難者
- **復興**：仮設住宅、がれき処理、国や隣町の支援、区画整理・高台移転
- **長期のリスク表示**：「今後 30 年以内に大地震が起きる確率 70%」
- **連鎖**：地震 → 火災 → 停電 → 断水 → 避難所生活 → 人口流出
- **表現の配慮**：実在の災害名は使わず、焦点は「防ぐ・立て直す」に置く

## 11. 隣の都市と外交

- 地図は地域（リージョン、たとえば 5×5 区画）。周りの AI 都市は概算のシミュレーションで動く
- **地形のプリセット**：湾岸型（埋め立てと津波）、河川平野型（洪水）、盆地・山あい型（土砂災害と雪）
- **最初のプリセット**：河川平野＋海岸型（北に山、中央に平野、川が南の湾に注ぐ）。洪水・津波・土砂災害・液状化をすべて扱える
- **性格**：観光都市、工業都市、ベッドタウン、過疎の村、軍事都市
- **関係度**：-100〜+100。交易、支援、発言、事件で上下する
- **協定**：交易協定、災害時応援協定、広域連携（共同ゴミ処理など）、不可侵条約、軍事同盟
- **競争**：企業の誘致、人口の奪い合い、ふるさと納税
- **対立の火種**：水利権、境界線、ゴミ処分場、被災者の受け入れ、選挙への干渉
- **合併**：話し合いで合併すると土地が広がるが、過疎地域や借金も引き継ぐ

## 12. 防衛と戦争（Tropico 風）

### 防衛隊

- **施設**：防衛隊本部、駐屯地、訓練場、沿岸監視所、防空施設。中央政府の基地を誘致することもできる（交付金が入るが、騒音と反対運動が起きる）
- **部隊**：歩兵隊、機動隊、救助隊、艦艇（湾岸）、航空隊（後期）
- **災害派遣**：防衛隊は災害時の救助にも出動する。軍事予算が防災にも役立つので、使い道が一つではない
- **兵器工場**：工業地域の産業として成り立ち、雇用と輸出を生む

### 紛争のエスカレーション

1. 外交摩擦（抗議、関係度の低下）
2. 経済制裁（交易の停止）
3. 境界の封鎖（通勤と物流が止まる）
4. 小競り合い（境界付近の施設に被害）
5. 紛争（本格的な衝突）

**プレイヤーの手段**：交渉、譲歩、県や中央政府への仲裁依頼、抑止（軍備の増強）、第三の町との同盟、経済制裁

### 戦争の進み方

- Tropico と同じく**自動解決**。戦力 × 補給 × 士気 × 地形で勝敗が決まる
- 部隊はジオラマの地図上を実際に動き、戦況が目で見える
- 街の被害は災害と同じ仕組み（被害と復興）で処理する
- **結末**：併合（強制的な合併）、賠償金、領土の割譲、相手を従属都市にする（税の一部が入る）
- **世論**：開戦直後は支持率が上がるが、長引くと厭戦気分で下がる
- **平和モード**：設定で戦争を無効にできる

### 内なる脅威

- 不満がたまると、デモ → 暴動 → 過激派の武装化、と進む
- **クーデター**：防衛隊が強く、防衛派閥の支持が低いと、防衛隊がクーデターを起こす（ゲームオーバー）
- 強い軍は隣町への抑止になるが、予算を食い、クーデターの危険と平和派の不支持を招く

## 13. 政治

### 派閥（Tropico 風）

| 派閥 | 喜ぶこと | 代表者（コネの相手） |
| --- | --- | --- |
| 経済界 | 減税、企業誘致、規制緩和 | 商工会議所会頭、私鉄社長 |
| 労働者 | 雇用、賃金、福祉 | 労働組合委員長 |
| 保守・伝統 | 神社・祭り、景観、治安 | 神社の宮司、町内会長 |
| 革新 | 教育、自由、情報公開 | 市民団体代表 |
| 環境 | 公害対策、緑地、再生可能エネルギー | 環境団体代表 |
| 防衛 | 軍備、強い外交 | 防衛隊司令 |

- 住民はそれぞれ派閥に属し、派閥ごとの支持率が選挙の票になる
- 市民の一部は時代や出来事によって派閥を移る

### コネと関係者

- **関係者（NPC）**：上の派閥の代表者に加えて、地元建設会社、県知事、国会議員、隣町の市長、地元新聞記者
- **関係度の上げ方**：会食、視察への同行、陳情に応える、便宜を図る
- **見返り**：私鉄の新線・沿線開発、補助金、企業誘致、災害時の優先復旧、選挙での支援
- **疑惑度**：便宜を図るほどたまり、新聞記者がかぎつけるとスクープ → 支持率低下 → リコール、落選
- **トーン**：軽い風刺。露骨な賄賂は高リスクにして、根回しや接待くらいの駆け引きを楽しめるようにする。コネに頼らない正攻法でもクリアできるバランスにする

### 選挙

- **選挙**：4 年ごと。公約を選び、演説と選挙カーで派閥の支持を集める。対立候補も出る（仲の悪い隣町が対立候補を支援することも）
- **落選したら**：次の 4 年間は AI 市長が運営する
  - AI 市長の性格：土建屋（公共事業のばらまき）、エコ（車道を削る）、ポピュリスト（減税で財政悪化）、タカ派（軍拡）
  - プレイヤーは在野の立場から、市民運動、メディアへの働きかけ、コネを使った工作ができる
  - 次の選挙で返り咲くと、AI 市長が残した街（と借金）を引き継ぐ

## 15. 見た目と音

- **ジオラマ表現**：被写界深度によるミニチュア感（強さは調整可能）、角の丸い建物、やわらかい影、暖かい光、ちょこちょこ動く人と車、地層が見える台座の断面
- **季節**：桜、梅雨、夏祭り、紅葉、雪
- **昼夜**：見た目の昼夜は、年の進み方とは独立して回す
- **音**：季節の環境音（セミ、風鈴、虫の声）、和風の lo-fi BGM、夕方 5 時のチャイム

## 16. ゲームモード

- **キャンペーン**：100 年の街づくり。100 年目に街の評価とエンディング
- **サンドボックス**：お金が無限。災害や戦争のオン／オフを自由に設定
- **シナリオ**：目標付きのチャレンジ（例：「埋め立て地の街を津波から守れ」「合併した過疎の村を立て直せ」「隣町との紛争を戦わずに収めよ」）
- **ハードモード**：自動セーブのみで、やり直しができない
