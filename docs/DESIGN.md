# 企画書（ドラフト）

> ブレスト中の内容をまとめたものです。決まったことは随時ここに反映します。

## コンセプト

**災害の多い日本の国土で、隣町と支え合い競いながら、100年続く街をつくる**

- Cities: Skylines 2 の主要機能を再現する
- 3D・ジオラマ風の高品質スタイライズドなグラフィック
- 独自の柱：**日本らしさ**、**災害と防災**、**隣の都市**、**コネと政治**

### ゲームの流れ

日本らしい街をつくる → その特徴が災害リスクを生む → 災害が街を試す → 隣の都市と支え合い、ときに競いながら復興する

| 日本らしい要素 | 生まれるリスク |
| --- | --- |
| 木造住宅が密集した下町、狭い路地 | 火災が燃え広がる。消防車が入れない |
| 海の埋め立て地 | 液状化、津波 |
| 山を削った住宅地 | 土砂災害 |
| 川沿いの平野 | 洪水、堤防の決壊 |

## 用途地域（6 種類）

| 区画 | 建つもの | 混在 |
| --- | --- | --- |
| 低層住宅 | 戸建て、低層アパート | 小さな店舗兼住宅のみ |
| 中高層住宅 | マンション、団地、タワマン | 1 階に店舗 |
| 近隣商業 | 商店街、コンビニ、スーパー | 住宅も可 |
| 商業 | オフィス、百貨店、繁華街、ホテル | 住宅も可 |
| 準工業 | 町工場、倉庫、物流センター | 住宅も可（騒音あり） |
| 工業 | 工場、コンビナート | 住宅不可 |

- 建物は**建築年代（旧耐震／新耐震）**を持ち、古い建物ほど地震に弱い
- 高さ制限、防火地域などは地区ごとの政策で上乗せする

## 災害と防災

- **災害の種類**：地震（揺れ・液状化・火災）、津波、台風（暴風・高潮）、豪雨（洪水・内水氾濫・土砂災害）、大雪、猛暑、火山
- **平時**：ハザードマップ表示、防災インフラ（堤防、遊水地、防潮堤、避難タワー、防災公園、延焼を止める広い道路、地下放水路）、耐震化の補助
- **予兆**：警報レベルの中で、いつ避難指示を出すかを決める
- **発災**：スロー再生、緊急車両の出動、停電・断水の連鎖、帰宅困難者
- **復興**：仮設住宅、がれき処理、国や隣町の支援、区画整理・高台移転
- **長期のリスク表示**：「今後 30 年以内に大地震が起きる確率 ○%」
- **壊滅の結末**：人口流出、財政破綻（財政再生団体）
- **表現の配慮**：実在の災害名は使わず、焦点は「防ぐ・立て直す」に置く

## 隣の都市

- 地図は地域（リージョン）。周りの AI 都市は概算のシミュレーションで動く
- **性格**：観光都市、工業都市、ベッドタウン、過疎の村
- **平時**：通勤の流れ、電気・水・ゴミの売り買い、広域連携
- **競争**：企業の誘致、人口の奪い合い、ふるさと納税
- **災害時**：応援協定による支援（関係性次第）
- **合併**：土地が広がるが、過疎地域や借金も引き継ぐ

## コネと政治

- **関係者（NPC）**：私鉄社長、地元建設会社、商工会議所、町内会長、県知事、国会議員、隣町の市長、地元新聞記者
- **関係度**を上げる手段：会食、陳情に応える、視察、便宜を図る
- **見返り**：私鉄の新線・沿線開発、補助金、企業誘致、災害時の優先支援、選挙での支援
- **リスク**：「疑惑度」がたまると記者がスクープ → 支持率低下、リコール、落選
- **選挙**：4 年ごと。支持率で再選が決まる
- **トーン**：軽い風刺として描く。コネに頼らない正攻法でも勝てるバランスにする

## 交通

- **公共交通**：バス、路面電車、鉄道、地下鉄、フェリー。停留所・路線・本数・運賃の編集、系統番号、駅ナンバリング
- **私鉄**：私鉄会社が沿線開発と、ターミナル駅の百貨店を手がける。関係が良ければ路線を提案でき、相互直通運転もできる
- **渋滞対策**：車線、一方通行、右折レーン、信号制御、立体交差、バイパス、踏切の高架化、パークアンドライド、時差出勤、ロードプライシング
- **可視化**：渋滞ヒートマップ、通勤の流れ（OD）

## 地区と政策

- 地区を塗り分けて町名を付ける（「○○町一丁目」を自動生成）
- **政策の例**：高さ制限、景観条例、防火地域、耐震補助、空き家対策、路上喫煙禁止
